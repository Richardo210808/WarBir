📌 Deskripsi Project
* Warung Biru (WarBir) merupakan website informasi dan promosi untuk Warung Biru Pak Supri, sebuah tempat makan yang berlokasi di samping Fakultas Teknik Universitas Jenderal Soedirman (Unsoed), Purbalingga. Website ini dirancang untuk memudahkan mahasiswa dan pengunjung dalam memperoleh informasi mengenai warung, melihat daftar menu beserta harga, melakukan pemesanan, serta mengetahui lokasi dan jam operasional.

🎯 Tujuan dan Latar Belakang
* Project ini dibuat sebagai bentuk pemanfaatan teknologi informasi dalam membantu mempromosikan usaha kuliner lokal, khususnya Warung Biru Pak Supri.
* Sebagai tempat makan yang berada di sekitar lingkungan kampus, Warung Biru memiliki target pengunjung utama berupa mahasiswa Fakultas Teknik Unsoed. Oleh karena itu, website ini diharapkan dapat menjadi media informasi yang praktis, menarik, dan mudah diakses.
* Melalui website ini, pengunjung dapat mengenal warung, mengetahui pilihan makanan dan minuman, serta melakukan pemesanan dengan lebih mudah tanpa harus datang langsung untuk mencari informasi.

✨ Fitur dan Section Website
1. Homepage
    * Menampilkan identitas Warung Biru.
    * Menyediakan gambaran singkat mengenai warung.
    * Menampilkan informasi lokasi dan jam operasional.
    * Navigasi menuju bagian menu dan pemesanan.
2. Tentang Kami
    * Menjelaskan profil dan keunggulan Warung Biru.
    * Memperkenalkan konsep makanan rumahan dengan harga terjangkau.
    * Menampilkan alasan mengapa Warung Biru cocok untuk mahasiswa.
3. Daftar Menu
    * Menampilkan berbagai pilihan makanan dan minuman.
    * Menyediakan gambar, deskripsi, dan harga setiap menu.
    * Memberikan informasi menu favorit.
3. Pemesanan melalui WhatsApp
    * Menyediakan tombol pemesanan pada setiap menu.
    * Menghubungkan pengunjung dengan WhatsApp Warung Biru.
    * Memungkinkan pengunjung mengirim permintaan reservasi melalui formulir yang diteruskan ke WhatsApp.
4. Lokasi dan Informasi Kontak
    * Menampilkan alamat Warung Biru.
    * Menyediakan informasi nomor WhatsApp.
    * Menampilkan jam operasional.
    * Menyediakan peta lokasi untuk memudahkan pengunjung menemukan warung.

🛠️ Teknologi yang Digunakan
1. HTML          : Menyusun struktur, desain, dan konten website.
2. Git & GitHub  : Mengelola versi kode dan kolaborasi project.
3. GitHub Pages  : Meng-hosting dan mempublikasikan website secara online.

🚀 Cara Menjalankan Website Secara Lokal
1. Clone repository
   * Buka terminal atau Command Prompt, kemudian jalankan perintah: git clone https://github.com/Richardo210808/WarBir.git
2. Masuk ke folder project
   * Buka terminal atau Command Prompt, kemudian jalankan perintah: cd WarBir
3. Buka project
   * Buka folder project menggunakan Visual Studio Code atau editor kode lainnya.
4. Jalankan website
   * Karena website menggunakan HTML tidak diperlukan instalasi dependency atau konfigurasi backend khusus.
   * Website dapat dijalankan dengan:
     - Membuka file index.html secara langsung melalui browser.
     - Menggunakan ekstensi Live Server pada Visual Studio Code untuk menjalankan website melalui server lokal.
